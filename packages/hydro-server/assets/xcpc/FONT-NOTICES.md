# Original XCPC fonts

The files in `fonts/` are copied without modification from
https://github.com/lihaoze123/xcpc-statement-generator/tree/84d822305f32dac2e0ac61c25c22145fbfc1d8cd/assets/fonts.
Embedded names and notices are retained. The AGPL template license does not
relicense these fonts or establish redistribution/embedding permission.

## Separate terms

- `cmunss.otf`, `cmunsx.otf`, `cmuntt.ttf`: Computer Modern Unicode, converted by
  Andrey V. Panov from TeX fonts; `cmuntt.ttf` also includes glyphs from Blue Sky
  fonts released by AMS. The embedded license identifies SIL Open Font License
  1.1. The upstream CMU notice/license is retained in `OFL-1.1.txt`, obtained from
  https://ctan.math.illinois.edu/fonts/cm-unicode/doc/OFL.txt.
- `NewCMMath-Book.otf`: New Computer Modern Math, © 2019–2021 Antonis Tsolomitis.
  The embedded license identifies the GUST Font License. See
  `GUST-FONT-LICENSE.txt` and `LPPL-1.3c.txt`, obtained from
  https://tug.org/fonts/licenses/GUST-FONT-LICENSE.txt and
  https://ctan.math.illinois.edu/macros/latex/base/lppl.txt.
  Original family/source distributions are available at
  https://ctan.org/pkg/newcomputermodern.
- `FZHTK.ttf`, `FZKTK.ttf`, `FZSSK.ttf`, `FZXBSK.ttf`: embedded notice
  `Copyright(c) Beijing Founder Electronics Co.,Ltd.2015`.
  The reference project provides these binaries, but no separate font license
  establishing redistribution or embedding rights. We do not represent them
  as open-source fonts or assert a grant of rights. Verify the necessary rights
  with Founder before publishing images, source archives or documents containing
  them. This notice is not a substitute for permission. They are retained to
  satisfy the explicitly requested original-font rendering, not silently replaced.
