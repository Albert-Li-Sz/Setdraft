# Hydro AI runtime

`@earendil-works/pi-ai` is the provider and streaming layer used by Hydro Problem Make's
local AI chat. It is kept as a workspace package so the server can support multiple API
protocols without depending on an Agent runtime.

The chat currently uses these protocol adapters:

- `openai-completions`
- `openai-responses`
- `anthropic-messages`

The adapters accept a model identifier, API key, optional base URL, context window and output
limit. Responses are exposed as text deltas and final usage events, and image content can be
passed when the selected provider supports it. Provider factories and the faux provider remain
available for tests and future integrations.

Useful entry points are:

```ts
import { streamSimple } from "@earendil-works/pi-ai/compat";
import type { Context, Model } from "@earendil-works/pi-ai";
```

Model catalog data is generated by `scripts/generate-models.ts`; do not edit generated catalog
files by hand. The package is built as part of the repository with `npm run build` and tested
with `npm run test` from its workspace.

The implementation retains the upstream provider implementations and their MIT license. See
the repository [dependency notes](../../UPSTREAM.md) for how this package is used here.
